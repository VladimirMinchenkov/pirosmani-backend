# Проект: Pirosmani Backend & Frontend

## Описание
Система доставки еды. Бэкенд на Ruby on Rails (API), фронтенд — веб/PWA, в будущем — мобильные приложения.

## Текущий стек
- Backend: Ruby on Rails, API v1
- База данных: PostgreSQL
- Frontend: (в процессе выбора) React + Next.js — веб + PWA

## Основные компоненты
- Админ-панель (управление меню, зонами доставки, заказами)
- API для фронтенда (корзина, расчёт доставки)
- Веб-версия / PWA (имитация приложения, устанавливается на телефон)
- В будущем: нативные приложения Android/iOS (React Native — по плану переиспользования кода)
